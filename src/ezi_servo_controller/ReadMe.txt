1. media_controller가 실행이 되면 gpio388을 통해 3.3v low, high를 날려 다인시스 보드를 재부팅 시킨다.
 + TCP연결이 안 되면 dignsys board를 컨트롤 할 수가 없다.  
 + TCP/SERIAL을 동시에 사용 할 수없다(다인시스 보드가 그렇게 만들어짐)
 + Serial 통신은 안정적이긴하나 제어할 수 있는 영상의 수가 제한적이며(8개) 이외의 명령어(현재 재생중인 영상 정보, 멈추기 등)
를 사용 할 수 없어서 TCP 모드로 사용 중인다. 
 - nvidia 보드가 서버, dignsys board가 client로 위와 같이 하여 통신 연결 시킨다. 

2. 서버에서 미디어 length, priority를 service를 통해 받는다.
 - 만약 서버와 통신이 안 될 경우를 대비하여 아래와 같은 작업이 이루어 진다. 
   + 만약 통신이 안 되면 기존에 저장되어 있는 파일(length.csv, priority.csv)을 읽어 실행한다. 
   + 통신이 되면 length, priority를 받은 후 파일로 저장한다. 
3. 현재 노출되는 영상 시간을 실시간으로 확인하면서 영상이 다 끝났다는 걸 확인하는다. 
4. 영상이 끝나면 다음 영상을 재생하라는 명령어를 보낸다. 

- 충전 모드 진입하면 1번 영상이 반복하여 재생된다.
- 주행 모드에 진입하면 1번 영상 반복 재생 모드가 해재된다.
- 주행 중 노출하고 싶지 않은 영상은 prohibitedList vector에 추가하면 된다. 
- 즉각적인 반응(노마스크 미디어)을 원할 시에는 isEmergencyCall 함수에 추가하면 된다.
- isEmergencyCall에 추가되지 않은 request가 들어오면 playlist에 추가되어 재생되고 있던 영상이 다 재생된 후 반영된다. 
- priority가 낮은 영상은 높은 영상이 재생시 개입할 수 없다.
